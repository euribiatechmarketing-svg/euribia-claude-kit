# Euribia asset library — manifest

Снимки и графики, които `contento-visual` (и другите агенти) използват при правене на съдържание.
Качи файла в правилната подпапка и добави един ред тук, за да го „вижда" агентът.

## Папки
| Папка | За какво |
|---|---|
| `brand/` | Постоянни брандови assets (лого варианти, текстури, фонове). |
| `presentations/` | Снимки за деки. |
| `carousels/` | Снимки за IG/LinkedIn карусели. |
| `posts/` | Снимки за single-image постове (IG/FB/LinkedIn). |
| `articles/` | Hero / in-article графики за блог/статии. |
| `ads/` | Визуали за реклами. |
| `_inbox/` | Сурови качвания, още неразпределени. Агентът може да предложи къде да отидат. |

## Как се ползва (важно)
- Поддържани формати: **PNG, JPG, GIF, WebP**. Макс **10MB** на файл.
- Поставянето във Figma става през **`upload_assets`** tool-а (не през плъгин код):
  - с `nodeId` → сетва снимката като fill на съществуващ placeholder node;
  - без `nodeId` → създава нови frames със снимката на текущата страница.
- `createImageAsync(url)` в плъгин кода **не** работи в този MCP — не разчитай на него.
